# BroCraft: Living World

Repository for BroCraft 1.2, the single-player voxel sandbox with the original Epic Audio soundtrack and Living World sound effects.

## Initial import

The repository has been initialized. The game bundle and Vercel configuration are being imported from the existing BroCraft Living World project. This README is not itself the playable game.

The intended hosting setup is a static site with no runtime server, no package installation, and no external audio downloads. The ready-to-host entry point will be `index.html` at the repository root.

World saves remain in the browser. Use the game's Export backup and Import save controls when moving an adventure between origins or devices.
